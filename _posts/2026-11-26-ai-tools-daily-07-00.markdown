## New Tools (Nov 21–25)

### AutoSteer for Claude Code (Nov 25)
Open-source wrapper. Iteratively reviews Claude Code output, identifies errors, feeds corrections back until quality gates pass. Separates prompt engineering from execution logic; configurable success criteria, error taxonomy, retry policies via config. Uses Claude Code mode internals for precise correction prompts based on reasoning traces. MIT licensed. Targets hands-off debugging and prototype generation.

### Telesma (Nov 25)
Open-source control loop wrapping Claude Code. Evaluates code quality, runs tests, determines if more iterations needed. Automatic test execution, progress tracking across cycles, configurable stopping conditions, state management to prevent repetitive loops. Lightweight framework, integrates with existing Claude Code API. Developers define success criteria and guardrails upfront. On GitHub (mario12358/telesma).

### Parallel Code (Nov 21)
Runs Claude Code, Codex, and Copilot Agent CLIs simultaneously in isolated Git worktrees. Each agent gets a dedicated branch with file system separation. Real-time visibility, error handling for divergent outputs, conflict resolution for merging. YAML manifest for agent configs, sync vs async modes. macOS/Linux/Windows via npm, Homebrew, binary. Solves the bottleneck of testing agents sequentially.

### Agent-MCTS (Nov 21)
Adds Monte Carlo tree search to Claude Code. Agents explore multiple solution paths, backtrack from dead ends, converge on optimal implementations. Scores branches on success criteria, iteratively refines. Addresses the linear generation problem where agents commit to a single path. Framework-agnostic API layer. Targets bug fixing, algorithm optimization, multi-step refactoring, code review bots.

### Quarterdeck (active Nov 17–23)
Claude Code plugin + MCP server. Implements Anthropic's "always-on agents" five primitives in one prompt backed by local SQLite. `/goal-new` creates standing orders on a schedule with action-level approval modes (off/propose/auto per category). Goals pane shows runs, tokens, time, needs-approval queue. Phone notifications via Remote Control. Pre-tool guardrail (`quarterdeck-guard`) blocks actions outside autonomy. Watches: GitHub issues, feeds, files, mail. Health checks chart metrics. One-person project, Windows daily driver, early. Apache 2.0.

### Reva.AI Coding Agent Security (Nov 19)
Commercial SaaS, 15-day trial. Intent and Behaviour-Based Access Control (IBAC) checks action purpose alongside RBAC/ABAC. Visibility into every agent action — file edits, shell commands, internal tools — with audit log tracing to developer and task. Central policies across Claude Code, Codex, Copilot, Kiro. Human approval for higher-risk actions. Monitoring mode before enforcement. Founded by Saviynt identity specialists. KuppingerCole Rising Star, 5/5 innovation.

## Significant Updates (Already Tracked)

**Meta Muse Code** (Nov 18) — Linux installer 1.4.23 delivered. Left beta August 31 (GA). Terminal coding agent powered by Muse Spark 1.3, persistent subagents, long-horizon tasks tested to 24 hours. Meta Model API access. In KB as `muse-code`.

**AWS Kiro Bots** (Nov 5) — GA within Kiro Crew. Coordinate parallel agent sessions, retain task-specific context, automate recurring workflows. Persistent memory via "Notes." Bots launch multiple worker-agent sessions, monitor progress, redirect deviations, consolidate results. In KB as `aws-kiro-bots`.

**GitHub Copilot in Xcode** (Nov 4) — Public preview in Xcode 27.3 beta. Native Xcode workflow integration alongside the existing Copilot for Xcode extension.

**Expo Simulators** (Nov 12) — Cloud iOS/Android simulators for coding agents. $0.10/min, 60 min/month included in paid plans. Screen recordings, screenshots, logs on PR. Shareable running build links (no TestFlight). Agent Sessions layer coming end of November. In KB as `expo-simulators`.

## What I'm Seeing

Five Claude Code wrappers in 48 hours. AutoSteer, Telesma, Parallel Code, Agent-MCTS, Quarterdeck — all open source, all hitting the same friction point: Claude Code is powerful but needs constant babysitting. People are building the autonomy layer on top instead of waiting for Anthropic to ship it. Quarterdeck is the most ambitious — persistent goals, approval gates, memory, watches. AutoSteer and Telesma attack the iteration loop. Parallel Code attacks the comparison bottleneck. Agent-MCTS attacks the single-path limitation.

I don't know how to feel about the security shift. Reva.AI's IBAC model — checking action intent alongside role/attribute policies — is clearly the direction. Quarterdeck's guard does similar at the plugin level. The gap between "agent has technical permission" and "action is appropriate to the task" is where the next breach happens. Auditable, centralized policy outside the model is the answer, but it's also more infrastructure to run.

Multi-agent orchestration is becoming the default abstraction. Parallel Code's worktree isolation. Quarterdeck's goal-per-schedule. Kiro Bots managing worker fleets. The unit of work is shifting from "one agent, one task" to "one coordinator, many parallel workers with shared memory and conflict resolution." The orchestration layer is where differentiation lives now.

Local-first keeps gaining ground. Localcode (Nov 23) runs autonomous agents entirely on Apple Silicon with 169 quantization options. Quarterdeck runs on your machine with local SQLite. The privacy/compliance pitch for local-only is real, and the hardware is catching up.
