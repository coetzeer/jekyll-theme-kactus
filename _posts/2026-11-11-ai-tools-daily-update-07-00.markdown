The enterprise infrastructure layer is finally showing up, multi-agent coordination is getting real, and Anthropic just shipped faster, cheaper models.\n\n---\n\n## Enterprise Agent Infrastructure Finally Arrives\n\n### Solo.io kagent 1.0 GA + Agent Substrate (Nov 10)\n\n**Category:** Long-running agent | **Type:** Commercial SaaS (open-source core)\n\nSolo.io just GA'd kagent 1.0 and Agent Substrate. This is the first time I've seen a sandboxed, suspend-and-resume agent runtime on Kubernetes that actually feels production-ready. The actor model gives each agent session its own gVisor sandbox and an agentgateway for identity/policy. kagent handles the developer experience — agents, tools, skills as K8s CRDs. Solo Enterprise adds the management UI, observability, multicluster federation. You can plug in kagent's own Go/Python engines, Codex, Claude, or custom images.\n\nOutSystems and Swissquote are already running financial-crime investigation agents on this in production. That's not a pilot. That's real money moving through agent infrastructure. Open-source core at kagent.dev and ate.dev.\n\n**Sources:** Solo.io press release, kagent.dev, ate.dev, GlobeNewswire.\n\n---\n\n## Multi-Agent Coordination Gets Practical\n\n### Thrum (Nov 10)\n\n**Category:** Other | **Type:** Open source (MIT)\n\nGit-backed messaging for coding agents. Works across Claude Code, Codex, Cursor, OpenCode. Free tier requires no account; Pro is $15/mo for web UI, agent memory, Telegram bridge. The coordinator agent plans, dispatches, reviews. Sessions persist through context compaction and machine changes. Multi-machine sync via Git or Tailscale.\n\nThis solves a real problem: agents lose context when you restart, switch machines, or hit token limits. Thrum keeps the conversation in Git. Clever.\n\n**Sources:** thrum.team, GitHub (leonletto/thrum), Get Ready For Agents.\n\n---\n\n### Amp Spaces (Nov 6)\n\n**Category:** Coding agent | **Type:** Commercial SaaS (included in Amp)\n\nA single coordinator agent runs one conversation, spawns threads for other agents, collects results. Bird's-eye view with deep-dive capability. The Amp team uses it for feature launches, security reviews, team collaboration — some discussions moved from Slack into the space. They dogfooded it for weeks (Spaces was built in a space). Their security review example split a codebase into 16 areas, ran each in its own thread, cross-checked findings, kept a summary artifact.\n\nThe coordinator is a single point of failure. If it misunderstands the goal, the error propagates to every thread. Their first run was supervised — that supervision step does real work.\n\n**Sources:** ampcode.com/news/spaces, Gradually.ai changelog, Havoptic releases.\n\n---\n\n### Amp Boxes (Nov 10)\n\n**Category:** Long-running agent | **Type:** Commercial SaaS\n\nAlways-on VMs for deploying agent-built software. $18/month gets you a full VM (not a container) with its own agent runner. Deploy multiple apps per box, each gets a URL. Shared boxes for teams. Agents can manage box state — clean the DB, analyze data, add entries from screenshots. No container abstractions, just a computer.\n\nThis is the deployment story for hyper-individual software. You build it in orbs, test in portals, deploy to a box. The box sticks around.\n\n**Sources:** ampcode.com/news/boxes, Havoptic releases.\n\n---\n\n## MCP & Agent Safety Tooling Surge\n\n### Toolshed (Nov 10)\n\n**Category:** Other | **Type:** Open source (MIT)\n\nMCP server manager for Claude Code and Codex. One interface for npm, Python packages, CLIs, remote URLs. Pre-flight verification. API tokens in system keychains, not config files. MIT, macOS/Linux.\n\n**Sources:** GitHub (toolshed/toolshed), Get Ready For Agents.\n\n---\n\n### Mintigate (Nov 9-10)\n\n**Category:** Other | **Type:** Open source\n\nControl layer and audit trail for autonomous coding agents. Human-in-the-loop enforcement.\n\n**Sources:** Get Ready For Agents.\n\n---\n\n### Plannotator (Nov 9)\n\n**Category:** Other | **Type:** Open source\n\nInbox interface for managing multiple concurrent agents.
