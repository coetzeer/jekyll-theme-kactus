## New Tools (Nov 17–19)

### Proton Lumo Desktop — Privacy-first desktop agent
Launched November 17. Windows/macOS/Linux app that runs locally and reaches into your files, shell, browser, and connected apps (Confluence, Dropbox, Jira, Proton Mail). MCP support. Granular per-connector permissions: auto, approve, or block. Conversations and data never used for ads or training. Free tier plus paid plans.

### OpenAI ChatGPT Wallet — Agentic commerce
November 17. Lets ChatGPT's "dot" agent shop and pay for you without exposing your card. Payment tokens per transaction, biometric verification. Pro users only (US, eligible Amex/Chase/Mastercard/Visa). No fees at launch. Partners: Amex, Mastercard, Visa.

### OpenCode Browse — Your actual browser, handed to agents
November 17. MCP server + Chromium extension. Agents get your real signed-in browser — cookies, logins, extensions, all of it. Background tab groups, human handoff for 2FA and payments. Works with Chrome, Edge, Brave, Arc, Vivaldi. Every MCP client (Claude Code, Cursor, Codex, Zed). Open source, local-only, no API keys.

### Microsoft MAI Model Family (7 models)
Ignite, November 17. Seven models targeting enterprise agent workloads. The cost claims are wild:
- **MAI Cyber 2 Flash**: GPT-6 Astra quality at <2% the cost
- **MAI Code 2**: 98% of GPT-6.1 Sol at 40% price. 96% of Opus 5.5 at 5% cost
- **MAI Code 2 Flash**: Routine coding tasks
- **MAI Image 2.7**: #1 in image editing, 1/5 the price of GPT Image
- **MAI Realtime 1**: Speech-to-speech, $0.01 per audio minute
- **Dragon Copilot Transcribe**: 10M patient encounters/month, halved error rates
- **Decision 1.1**: Model routing, 50x faster and 79x cheaper than GPT-Sol 6.1
Maia 200 accelerator in production (1.7x tokens/watt). In GitHub Copilot, Foundry, Azure AI.

### Salesforce Bridget — Enterprise no-code automation
November 17. Learns by exploring apps in a sandbox, builds reusable tools, executes deterministically (100% benchmark accuracy), self-heals when UIs change, keeps an audit trail. Regrello Nov 18, MuleSoft Dec. Freeport-McMoRan cut supplier onboarding from weeks to days (400+ suppliers). Finance team automated 70 quarterly tasks.

### AWS SMART — WhatsApp plumbing for Bedrock agents
November 17. Open-source Python SDK + Terraform. Handles message verification, voice notes, conversation persistence, templates, scheduling. Three blueprints: starter, personal assistant, appointment scheduler. Framework-agnostic (Strands, LangGraph, Pydantic-AI). AWS calls it sample code for non-production use.

### Gemini Tasks — Agent that calls, books, pays
November 17. Gemini mode that phones businesses, books appointments, buys things via Google Pay, reads your inbox. Free in six countries (advanced features US-first). Built into the Gemini app.

### Gemini 4 Neon — The middle child that matters
GA November 18. Sits between Carbon (heavy) and Hydrogen (light). 1M context, $3/$15 pricing, Antigravity Orchestrator support. Targets complex coding, analytical reasoning, scientific research, enterprise workflows. In Gemini API, AI Studio, Android Studio, Antigravity, GitHub Copilot, Gemini app (Pro/Ultra), Fairwind Program for cyber.

### Zoho Desk Blended Agents
November 18. Automates routine support tickets, spots recurring issues, escalates the nuanced ones to humans. Blended AI/human workflow.

### Flexxible FlexxSolve — Autonomous IT support
November 19. US and Canada. Finds the cause, fixes it, verifies the fix — all within company rules. 20% of tickets resolved day one, climbing to ~50% as the knowledge base grows. ~7 minutes average fix time, 24/7. First 100 issues free.

### Mercans NovAI — Agentic payroll across 100+ countries
November 19. AI agents run the full payroll cycle, humans keep every decision. Early access for large employers, full release 2027. London/Dubai HQ.

### ASUS ProArt GR1X — Local agent hardware
November 19. NVIDIA RTX Spark mini PC, 1.1L, up to 1 petaflop FP4, 128GB or 64GB unified memory. Runs 120B models with 1M context locally. No cloud, no per-token fees. Validated stack: Hermes Agent, ComfyUI, Adobe CC, ASUS Zenni Claw and MuseTree.

### Microsoft Foundry — Agent fleet governance
November 19. GA/preview. Agent identities via Entra, deployment policies, tool and network controls, cost visibility with thresholds, safety guardrails. Start with a single subscription.

### ChatGPT for Accounting — Vertical agent for finance
November 18-19. Accounting Plugin v1.0.0 connects to QuickBooks, Xero, NetSuite, BILL, FreshBooks, Rillet, Campfire. Five focus areas: invoices, bank reconciliation, month-end reports, data entry, audit prep. Human oversight required for final changes. Work and Business plans.

### ResearchMonkey AI — Citations that actually link
November 19. Student and researcher platform. Every summary carries citations with word-for-word quotes linked to the exact page, paragraph, or timestamp. Fixed structure: TL;DR, summary, takeaways, stats block. YouTube becomes a timeline. Presentations get slide-by-slide breakdown.

## What I'm Seeing

Three threads converging:

1. **Agents getting real permissions** — Lumo, Browse, Tasks, FlexxSolve, NovAI, Bridget. Not chat anymore. They act. The permission models are the product now (granular, audited, human-in-the-loop).

2. **Cost collapse at the model layer** — MAI Cyber at <2% of GPT-6 Astra. MAI Code at 5% of Opus. Decision 1.1 at 79x cheaper than GPT-Sol. Qwen4-Max at $4.50/M output (91% below GPT-6 Astra). You can afford to run frontier models in loops now.

3. **Local-first as a category** — Lumo (desktop), ProArt GR1X (hardware), Browse (your browser). Privacy and cost both push here. ASUS's "always-on home for local agents" phrasing is telling.

The verification-over-trust theme from LetThemBuild (Nov 14) is spreading. ResearchMonkey's cited summaries. Bridget's deterministic execution with audit trails. Foundry's governance. FlexxSolve's verified fixes. Multiple models checking each other. Humans keeping decisions. This feels like the next phase: not "smarter models" but "models you can actually let loose."
