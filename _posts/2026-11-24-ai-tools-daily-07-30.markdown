## New Tools (Nov 22–23)

### Anthropic Claude Ship — PR review, fixes, and approval agents

Launched November 23. Three agents that take a GitHub pull request from review to an approval decision: Code Review (finds bugs, style issues, security problems), PR Steward (implements fixes autonomously across multiple files), and Claude Approvals (approves routine changes per a team policy file). Accessed via `/ship` in Claude Code. Beta for Team and Enterprise plans only — Pro is excluded. Eligible Enterprise orgs get $10,000–$50,000 in review credits. Token-billed via usage credits. The policy file is the control surface: teams decide what's routine enough for auto-approval. Code Review was already GA; PR Steward and Claude Approvals are the new beta pieces.

### Random Labs Slate V1 — Swarm-native autonomous coding agent

Launched ~November 21. Y Combinator-backed startup. First "swarm-native" agent: massively parallel orchestration, not a single agent. Lives in your codebase with deep context across huge repos (tested on 1.1M+ lines). VS Code extension works alongside Cursor/Claude Code. Open source (Apache 2.0). Founders: Kiran (CEO) and Mihir Chintawar (CTO). Written parts of its own codebase. Positions differently from Cursor/Claude Code/Devin — it's about orchestrated swarms, not one smart agent.

### Sarvam-105B-1711 — Open-weight agentic model, Flash-Lite class

Released November 22. New checkpoint of Sarvam 105B MoE (10.3B active params) optimized for conversational agent workloads: tool calling, instruction following, agentic tasks, Indian languages. 160K context. NVFP4 65GB checkpoint runs on a single RTX PRO 6000 Blackwell GPU (99 tok/s). Blended price $0.15/M tokens — down from $0.44, beating Gemini 3.5 Flash-Lite ($0.85) and Gemma 4 31B ($0.54) on agent benchmarks at 5x lower cost. 73.9 average across 8 conversational agent benchmarks. Tau2 tool calling 85.5 (best tested). 69.5% Tau2 pass^4 consistency (highest). Voice fine-tune powers Samvaad (12 Indian languages). Apache 2.0, BF16 + NVFP4 on Hugging Face. On-prem viable for banks/gov/defense: single GPU, no network required. Flash-Lite class — built for high-volume chat/agent workloads, not research-grade reasoning.

## Significant Updates (Already Tracked)

**Cognition Devin Bots** (Nov 17) — Persistent goal-owning agents that lead teams of Devin sessions for weeks. Own high-level goals ("keep Android at parity with iOS"), decompose into parallel tasks, review PRs, run post-deploy QA. Shared memory across sessions. Max/Teams/Enterprise only. One engineer reported 22 of 44 days autonomous while it built an Android app. In KB as `cognition-devin-bots`.

**PagerDuty Paige SRE Agent** (GA Nov 3, Escalation Policies GA Nov 19, MCP Server GA Nov 23) — Virtual on-call responder added to escalation policies. Ingests runbooks, change events, logs, topology. Recommends remediation with human-in-the-loop. Shared memory: every incident sharpens future performance. PD Reliability Platform (rebranded Operations Cloud), Slack/Teams native. MS Teams and Virtual Responder still Early Access. Autonomous resolution "coming soon." In KB as `pagerduty-paige-sre-agent`.

**Google Genie 4 World Model** (Nov 19) — Continuous 720p @ 24fps with synchronized native audio from text/image prompt. Real-time keyboard controls and live text prompts during generation. SynthID watermarking. Via Gemini API (Interactions API) and Google AI Studio. Google AI Pro waitlist. Distinct from Veo — interactive world model with physics-aware continuity, native audio. In KB as `google-genie-4-world-model`.

**Google Gemini Computer Use (Mac)** (Nov 19) — Gemini app for Mac clicks, types, fills forms across local files, desktop apps, web in isolated background window with live preview. User controls app access, approves key actions. English, US rollout first. Mirrors Anthropic Computer Use but in consumer Gemini app with isolated window UX. In KB as `google-gemini-computer-use-mac`.

## What I'm Seeing

Three threads converging:

**Agents are getting real permissions.** Claude Ship's policy file. Paige on escalation policies. Devin Bots owning goals for weeks. Gemini computer use with app-level gates. Apple's 14-step warning for competitors while building its own. The permission model *is* the product now — granular, audited, human-in-the-loop by default.

**Cost collapse at the model layer continues.** Sarvam-105B-1711 at $0.15/M tokens for Flash-Lite class agent performance. That's 5x cheaper than Gemini 3.5 Flash-Lite, 3x cheaper than Gemma 4 31B. Inkling 2 Mini (Nov 20) runs frontier coding on a laptop for zero marginal cost. You can afford to run frontier models in loops now.

**Swarm/orchestration as the new abstraction.** Slate V1 is explicitly "swarm-native." Devin Bots manage teams of Devins. Antigravity added `/swarm` (Nov 12). The unit of work is shifting from "one agent, one task" to "one coordinator, many parallel workers." The orchestration layer is where the differentiation lives now.

The verification-over-trust theme keeps spreading. ResearchMonkey's cited summaries. Bridget's deterministic execution with audit trails. Foundry's governance. FlexxSolve's verified fixes. Multiple models checking each other. Humans keeping decisions. Not "smarter models" but "models you can actually let loose."
