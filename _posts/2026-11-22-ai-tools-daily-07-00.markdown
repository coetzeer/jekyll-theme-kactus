## New Tools (Nov 21–22)

### CodeAlta — Agentic dev environment in C#/.NET, Desktop + TUI + CLI

Released Nov 21. Open-source agentic development environment written entirely in C#/.NET. Three interfaces: Desktop app, terminal UI (altatui), and CLI (altacli) — same profile, providers, sessions across all. Fleet feature runs sessions on other machines (Mac, build box, cloud VM) over SSH or Tailscale; end-to-end encrypted, server relays but reads nothing. Sandbox built on Microsoft MXC isolates commands from credentials and SSH keys. Supports Claude Code, Codex, GitHub Copilot, OpenCode, llama.cpp, ACP agents (Cursor, Gemini CLI, Qwen Code). Worktrees, automations, plugins, canvases, mobile app via Tailscale. No telemetry. BSD-2-Clause. 351 stars, 42 forks.

**Category:** Coding Agent / Long-Running Agent | **Open Source** | **Cost:** Free + model costs

### Eigin — Personal AI agent for iOS, privacy-first, local-first, European

Danish company (Eigin ApS). iOS app (TestFlight beta), more platforms on roadmap. Chats, memories, and settings stored on device. Cloud AI runs in Europe and doesn't store prompts or responses. Pay-as-you-go credits (~€10–20/mo typical) or bring your own provider (ChatGPT Plus, local model). Closed-set tool model: fixed tools, permissions in execution path. AGPL. Open source at code.eigin.ai.

**Category:** Personal AI Agent / Long-Running Agent | **Open Source (AGPL)** | **Cost:** Free app + optional cloud credits

### DreamCoder — Frontier coding harness with tiling window manager in browser

By Mickey Petersen (Mastering Emacs author), announced Nov 20. Runs in browser on all three platforms. MCP, backgroundable sub-agents, shell commands, terminal windows, skills, hooks. Expected two to three months of work; took 15. 142 points on HN.

**Category:** Coding Agent | **Open Source** | **Cost:** Free (bring your own model)

### OpenComputer — Open-source Devin alternative

Mention @Computer in a Slack thread, result lands as a PR from a Claude Code, Codex, or OpenCode session. Opens PRs 3.3x faster than Devin (vendor benchmark). 766 stars, Apache-2.0. From DiggerHQ.

**Category:** Coding Agent / Long-Running Agent | **Open Source (Apache-2.0)** | **Cost:** Free + model costs

### Claude-BugHunter — Claude Code skill bundle for bug hunting and red-teaming

Merge Nov 20 adds get_report: a public, keyless, read-only HackerOne MCP tool fetching disclosed reports live. 14,513 stars, MIT. By elementalsouls.

**Category:** Coding Agent Skill/Plugin | **Open Source (MIT)** | **Cost:** Free (requires Claude Code subscription)

### Browser Use 1.0.7 — MCP calls no longer time out at 60s

Published Nov 20. Long browser_exec now replies within 50s with output so far; calling again with empty code returns the rest.

**Category:** Browser Automation / MCP Server | **Open Source** | **Cost:** Free

### NanoClaw 2026.11.0 — Agents create agents from templates

Published Nov 20 18:45 UTC. New agent groups get only their model key. Eight changes need action from some installs, including a OneCLI database password that closes a critical security hole.

**Category:** Long-Running Agent / Agent Framework | **Open Source** | **Cost:** Free

### Paradev desktop v2.0.11 — Cloud boxes stop idle sandbox after 15 min

Published Nov 20 19:35 UTC. Desktop shows when you're in a subagent view and how to get back.

**Category:** Long-Running Agent / Agent Desktop | **Commercial / Open Core** | **Cost:** Subscription-based

### Stitch Skills — Agent Skills library for Stitch MCP server

Three fixes merged Nov 20. 11,094 stars, Apache-2.0. By google-labs-code.

**Category:** Agent Skills/Plugins | **Open Source (Apache-2.0)** | **Cost:** Free

## What I'm Seeing

Three threads hardening:

1. **Language diversity in agent frameworks** — CodeAlta (.NET), NanoClaw (Go?), Orca (Rust/TypeScript?), DreamCoder (browser/JS). The Python monopoly on agent tooling is cracking.

2. **Local-first as a distribution strategy** — Eigin (iOS local storage, European cloud), CodeAlta (no telemetry, sandbox, fleet over Tailscale/SSH), DreamCoder (browser-based, runs locally). Privacy and data sovereignty are becoming product differentiators, not just compliance checkboxes.

3. **Skills/plugins as the new package manager** — Claude-BugHunter, Stitch Skills, Browser Use MCP, CodeAlta plugins/ACP agents. The agent harness is becoming a platform; the value is in the skill ecosystem.

The verification-over-trust theme continues. OpenComputer's PR gate. Claude-BugHunter's keyless HackerOne tool. CodeAlta's sandbox and signed rules. NanoClaw's security fix. Humans keeping decisions. This isn't "smarter models" — it's "models you can actually let loose."
