Four new things since the Oct 23 run. Three are open source. One is a framework from Cursor that lets you deploy agents to their cloud. Here's what's worth knowing.

## Agent Tree — finally, a way to see what your Claude Code agent is actually doing

**Category:** Long-running agent (observability)  |  **Type:** Open source (MIT)  |  **Released:** Oct 26, 2026

This is the tool I've been waiting for. You run `yeet run .` in a terminal and it attaches to your running Claude Code session, rendering the live process tree — every shell, MCP server, node process, and build tool the agent spawns, updated as it happens. New processes flash green with a `+` for a few seconds; dead ones linger as dim strikethrough lines with their exit status before dropping out. It uses eBPF tracepoints (`sched_process_exec` / `sched_process_exit`) so the tree stays current without re-polling `/proc`. Zero dependencies, read-only, MIT license. If you've ever stared at a spinning cursor wondering what your agent is *actually* doing right now, this answers it.

**Source:** GitHub (yeet-src/claudetree), emergent.sh

## Microsoft Agensh — 1,024 agents, no boss

**Category:** Long-running agent (multi-agent harness)  |  **Type:** Open source (MIT)  |  **Released:** Oct 24, 2026

Microsoft Research open-sourced a decentralized multi-agent harness that scales to 1,024 concurrent coding agents with no central orchestrator. Agents discover and claim sub-tasks, share findings, verify results, and merge progress asynchronously. On the Pandoc rebuild benchmark, pass rates climbed from 33.89% (single agent) to 55.06% at 1,024 agents. The interesting part isn't the score — it's that as the team grew, the agents developed their own division of labor, review workflows, and specialist roles. No one told them to. Docker Compose harness included. MIT license. This feels like a genuine architectural shift, not just "more agents."

**Source:** GitHub (microsoft/Agensh), arXiv: "Agensh: Scaling Organizational Intelligence to 1,024 Agents"

## iFlytek Spark-X2.6 — China's homegrown 293B MoE for coding

**Category:** Other (coding/agentic foundation model)  |  **Type:** Open source (Apache 2.0)  |  **Released:** Oct 22, 2026

293B total parameters, 30B active per token (MoE), 1M token context. Trained entirely on domestic Chinese computing infrastructure — iFlytek emphasizes this heavily. They claim breakthroughs in coding and agentic capabilities, deployed on a 10,000-card domestic inference cluster. Real-world deployment in state-owned enterprises, education, healthcare, and judicial services reportedly outperforms public benchmark scores. Apache 2.0 license. The "domestic compute" angle is political as much as technical, but the artifact is real and the benchmarks are competitive. Worth watching if you care about non-US foundation models.

**Source:** People's Daily Online, Global Times, iFlytek 1024 Developer Festival

## Cursor Agent SDK — agents as code projects

**Category:** Coding agent (framework)  |  **Type:** Commercial platform (Cursor) + open source SDK  |  **Released:** Oct 20, 2026

Cursor now lets you define an agent as a folder of code: `instructions.md` is the prompt, `tools/` are typed actions, `skills/` are procedures the model loads on demand, `mcp-connections/` add tools from MCP servers, `channels/` define where the bot receives messages (GitHub PRs/comments/CI, GitLab, Bitbucket, Slack mentions/DMs, webhooks, cron). Run `agent-sdk dev` locally with a playground, `agent-sdk deploy` to Cursor's infrastructure. Includes evals and templates for security reviewer, PR autofixer, Linear/Jira triager. The "agents as code" framing is the right one — version control, CI, code review all apply. But you're locked into Cursor's cloud for deployment. The SDK itself is open source; the runtime isn't.

**Source:** cursor.com/changelog

---

**Bottom line:** The observability tool (Agent Tree) solves a real pain point today. Agensh is a research result that might change how we think about multi-agent systems. Spark-X2.6 is a credible non-US open model. Cursor's SDK is a polished product move that locks you into their platform. Pick your poison.
