Seven things since the November 5 run. One major platform release (the one you're reading this on), two coding-agent tools, one open-weight model, two enterprise governance plays, and a voice model. Here's what's worth knowing.

## Hermes Agent v0.23.0 — The Hearth Release (Nov 5)

**Category:** Other (Agent platform) | **Type:** Open source (MIT, Nous Research) | **Released:** Nov 5, 2026

The platform this cron job runs on just shipped its biggest release yet. "The Hearth Release" puts the full Desktop workspace in a browser tab — one gateway serving every conversation across devices and apps. Group Chats now route their own conversations with per-user routing. The terminal draws images inline and lets you `/rewind` conversation history. Spend limits for paid tools, self-updating plugins, multi-machine Desktop access. 10,080 commits since v0.22.0, ~1,950 merged PRs, 666 contributors.

This is the unification Nous has been building toward: Desktop, CLI, and Web clients behind a single persistent gateway. If you've been running Hermes, update. If you haven't, this is the version to start with.

**Source:** GitHub (NousResearch/hermes-agent/releases/tag/v0.23.0), NousResearch X announcement, AlphaSignal.

## Lmux — Lightweight macOS Terminal for Claude Code and Codex (Nov 5)

**Category:** Coding agent (Terminal interface) | **Type:** Open source (MIT) | **Released:** Nov 5, 2026 (Show HN)

A native macOS terminal built specifically for Claude Code and Codex workflows. Launched via Show HN (github.com/sooftware/lmux). The pitch: reduce context-switching for developers who live in the terminal by bringing AI-assisted coding directly into the native terminal environment. Platform-specific APIs for performance, compile from source. Third-party tool extending Claude Code beyond Anthropic's official interfaces. macOS only.

**Source:** Hacker News (Show HN), Emergent.sh, RisingTerms.

## AWS Kiro Crew Bots — Persistent Agents with Memory (Nov 5 GA)

**Category:** Long-running agent (Agent workspace) | **Type:** Commercial (AWS) | **GA:** Nov 5, 2026

Named, long-running bots inside Kiro Crew with their own memory, sessions, and dashboards. Instead of juggling isolated agent sessions, you define a bot for a recurring job — monitoring failed builds, reviewing code changes, checking release readiness — and it runs continuously, coordinating worker sessions. Each bot has a name, avatar, ongoing chat, and customizable goals/milestones. Free tier: 50 credits; Pro: $20/mo (1,000 credits). Runs on laptop, Mac Mini, or EC2. Built on Anthropic's Claude models, evolved from internal MeshClaw project. No AWS account required.

This shifts the pitch from "generate code on demand" to "assign ongoing ownership with memory and supervision."

**Source:** Kiro blog (kiro.dev/blog/crew-bots/), AWS Japan blog, VentureBeat, CryptoBriefing.

## Ripple-65B Preview — Dense 65B Beating Larger Models on Agentic Coding (Nov 4)

**Category:** Coding agent (Foundation model) | **Type:** Open weights (Apache-2.0, Recursive Intelligence) | **Released:** Nov 4, 2026

65B dense model trained from scratch on 12T tokens with 1M context. Claims SOTA for US open-weight models on agentic coding benchmarks, outperforming Muse Spark 816B, Beam 501B, Inkling 975B, and Nemotron 3 Ultra 550B. $32M compute budget. Trails on math and safety benchmarks. First dense open-weight LLM from Recursive Intelligence (chip-design platform company). Preview release.

If you want a US open-weight model for coding agents that punches above its weight class, this is the one to test.

**Source:** Ricursive.com/ripple, MindStudio benchmarks, OfficeChai.

## CrowdStrike Agent Insider Threat Detection — Security for AI Agents (Nov 4)

**Category:** Other (AI Agent Security) | **Type:** Commercial (CrowdStrike) | **Announced:** Nov 4, 2026 (Fal.Con Europe)

Learns normal behavior of every AI agent and its operator, flags deviations even when no policy is violated. Routes alerts into coordinated multi-agent investigations across endpoint, identity, SaaS, cloud, network. Falcon Guardian AI Kill Switch terminates rogue agents immediately. Also: Agentic Adversary Emulation (early access) simulates how attackers chain weaknesses via autonomous agents. Some features Q4 2026, policy-drift guardrails Q1 next FY.

The framing: AI agents are both insider threats and adversaries. "You pay this insider in tokens."

**Source:** CrowdStrike press release, IR site, SecurityBrief Asia.

## Kong AI Management Expansion — Governance Layer for Agentic AI (Nov 4)

**Category:** Long-running agent (Agent Governance) | **Type:** Commercial (Kong) | **Announced:** Nov 4, 2026

Major expansion of Kong AI Management in Konnect. Seven new capabilities: AI Registry (governed inventory of models, agents, MCP servers), AI Gateway 2.3 (runtime management, policy enforcement), Kong Identity (consistent identity for humans/apps/agents), Token Vault (runtime credential brokering, GA), AI Cost Management (granular attribution, budgets, showback/chargeback, optimization), Advanced AI Observability (full session and turn-level visibility), all unified in Kong Konnect control plane.

Addresses the shift from individual model calls to agent-driven workflows with multiple models, MCP servers, tools, and agents acting on behalf of users.

**Source:** Kong press release, blog posts (cost management, registry, token vault).

## Inkling 2 Small — Thinking Machines Lab's 594B MoE via Tinker (Nov 5)

**Category:** Other (Foundation model) | **Type:** Commercial (Thinking Machines Lab) | **Released:** Nov 5, 2026

594B MoE with 17B active parameters and 292M vision encoder. Accessible only through Tinker platform — run and fine-tune, but weights are gated (not downloadable). Basis for Cognition's SWE-2 Flash. Mira Murati's lab, weights held back.

**Source:** Superpower Daily, AI Weekly.

## Phonic-1 — Speech-to-Speech for Voice Agents (Oct 29)

**Category:** Other (Voice AI) | **Type:** Commercial (Phonic) | **Launched:** Oct 29, 2026

Multilingual speech-to-speech model (not TTS+STT pipeline). 50+ languages, switches mid-conversation while preserving speaker identity. Can invoke external tools while caller is still speaking. $27.5M Series A (First Round Capital), total $31.5M. Positions in speech model layer for voice agents.

**Source:** Phonic blog, Slator.
