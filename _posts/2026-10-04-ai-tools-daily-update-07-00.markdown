## Gemini 4 Argon — Google's new frontier model for cyber defenders

**Category:** Other (Frontier model / Cyber defense)  
**Type:** Commercial (SaaS, limited access)

Google dropped Gemini 4 Argon on October 1. It's their latest frontier model, but you can't use it — not yet. They're rolling it out exclusively to trusted cyber defenders through the Fairwind Program. The kicker: those defenders get a "guardrail-free" version. Everyone else waits.

---

## AKASA Autonomous AI Platform — Inpatient coding and CDI gone autonomous

**Category:** Long-running agent (Healthcare / RCM)  
**Type:** Commercial (SaaS, enterprise)

Launched October 2. AKASA used to do prebill review. Now they're going full mid-cycle autonomy: inpatient medical coding and clinical documentation integrity (CDI). The platform builds custom models for each health system, trained on their own documentation and coding decisions. Built for hospital revenue cycle management — not a generic tool retrofitted for healthcare.

---

## Salesforce AIforce — "AI replaces the UI"

**Category:** Long-running agent (Enterprise AI interface)  
**Type:** Commercial (SaaS, enterprise)

Dreamforce 2026. Salesforce unveiled AIforce — an AI interface layer that brings Data 360, Customer 360, and Agentforce to any AI interface. The engine underneath is the Headless Toolkit: open architecture exposing Salesforce via MCPs, APIs, plugins, skills. There's also a Headless Experience Layer that renders rich UI widgets natively across any surface. The tagline is literally "AI replaces the UI."

---

## HubSpot Breeze Agents — Four specialized agents plus Agent Hub

**Category:** Long-running agent (Marketing / CRM automation)  
**Type:** Commercial (SaaS, HubSpot platform)

Fall 2026. HubSpot launched four agents: Campaign (plans end-to-end from a goal), Content (researches first — pulls brand voice, audience data, competitive landscape — then writes blogs, LinkedIn posts, landing pages), Nurture (personalizes every email with CRM data and live research), Revenue (connects ChatGPT Ads for attribution). Agent Hub manages the sprawl. Breeze Assistant coordinates them from natural language. Adoption doubled: 19% of Pro Plus customers used agents in August, up from earlier in the year.

---

## GitLab 19.4 Duo — Agentic automation with governance and cheaper models

**Category:** Coding agent (DevSecOps / CI/CD automation)  
**Type:** Commercial (SaaS, GitLab platform)

Early October. GitLab extended Duo's agentic automation across more workflows. New governance: admins control which AI models agents can use. New visibility: per-user and per-group GitLab Credits metering. New economics: up to 4x more AI actions per credit with lower-cost model options. There's a public-beta self-check tool so agents can verify their own work. Plus new MCP server tools and community-contributed agent tools for project metadata, branches, MRs, and Duo sessions.

## Reinventing.AI — Eight open-source AI employees under MIT

**Category:** Long-running agent (Business automation)  
**Type:** Open source (MIT)

September 19. Reinventing.AI dropped eight "AI employee" packages on GitHub under MIT — commercial use included, no membership needed. They cover 59 scheduled business routines (GTM, SEO, Sales, Support, four more). Run locally on your machine across 11 agent harnesses. Repository: github.com/markfulton/ai-employees

## OpenAI Codex CLI — Agent command center history, GPT-6 Sol/Luna

**Category:** Coding agent  
**Type:** Commercial (SaaS/CLI)

October 2. Codex CLI shipped agent command center history browsing (keyboard-accessible "Show more" for older tasks, fullscreen transcript selection), X11 middle-click paste, projectless sessions with workspace defaults. Also rolling out GPT-6 Sol (complex coding and agentic workflows) and GPT-6 Luna (focused, high-volume tasks) at lower token prices than GPT-5.6.

## Google Antigravity Enterprise — IDE extensions, desktop app, CLI

**Category:** Coding agent (Enterprise IDE integration)  
**Type:** Commercial (SaaS, Gemini Enterprise subscription)

August 20 announcement, now in enterprise preview. Antigravity lands in VS Code, Visual Studio Preview, JetBrains Preview (IntelliJ, PyCharm, WebStorm, GoLand, CLion, Rider), Zed Preview. Plus Antigravity 2.0 desktop app and CLI. Multi-agent orchestration runs in the wider ecosystem. Part of eligible Gemini Enterprise subscriptions.
